# Тахир: туда и с чак-чаком

Шуточный русскоязычный опросник: шесть вопросов и четыре результата. Статический сайт без сборки и серверных зависимостей.

## Запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт через доступный в вашей среде просмотр порта 8000. Для локальной разработки — http://localhost:8000.

Шрифты Google Fonts необязательны: без сети используются системные шрифты. Ответы обрабатываются в браузере и никуда не отправляются. При равенстве баллов выбирается первый результат с максимальным баллом. Копирование результата требует поддерживаемого браузером Clipboard API.
